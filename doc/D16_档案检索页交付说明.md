# D16 交付说明 — 档案检索页（多条件组合查询）

> 日期：2026-08-20
> 状态：✅ 完成并联调验证通过

## 一、本次交付

| 模块 | 内容 |
|---|---|
| 后端 | 独立检索接口 `/api/archive/search`,扩展多条件查询 + 排序 |
| 权限 | 新权限码 `archive:search:query`(菜单 50),**分配给全部 3 个角色——普通用户 lisi 首次获得检索能力** |
| 前端 | 检索页 `/archive/search`:多条件表单 + 结果表格 + 分页 |

## 二、后端接口

**GET /api/archive/search**(权限 archive:search:query,复用 pageFiles 逻辑)

| 参数 | 类型 | 说明 |
|---|---|---|
| title / archiveNo / keywords | 模糊 | 题名/档号/关键词 |
| typeId / year | 精确 | 门类/年度 |
| retentionPeriod / securityLevel | 精确 | 保管期限/密级(字典值) |
| orderByColumn / isAsc | 排序 | 白名单列(create_time/year/title/archive_no 等),防 SQL 注入 |

## 三、前端（检索页）

- 多条件表单:题名/档号/关键词输入 + 门类/年度/保管期限/密级下拉(字典)
- 结果表格:档号/题名/责任者/年度/保管期限/密级/状态 + 分页
- 普通用户(lisi)登录后侧边栏出现"档案检索"
