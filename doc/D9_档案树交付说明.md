## 二、后端接口

### 档案树 GET /api/archive/tree（权限 archive:fonds:query）
返回三级树：
```
[
  { id, label: "计算机学院", type: "fonds",
    children: [
      { id, label: "文书档案", type: "type",
        children: [ { id: 2024, label: "2024年", type: "year" }, ... ] } ] }
]
```
年度从案卷表 `da_volume` 按门类聚合 `DISTINCT year`（倒序）。

### 案卷分页 GET /api/archive/volume/page（权限 archive:volume:query）
参数：fondsId / typeId / year / title（模糊）/ 分页。D9 仅只读；CRUD 与档号生成留 D10。

## 三、前端（views/archive/overview/index.vue）

- 左侧 `el-tree`：三级目录（全宗/门类/年度 图标区分），默认展开
- 点击节点：按层级设置过滤（fonds→fondsId、type→typeId、year→year），刷新右侧列表，顶部显示当前路径
- 右侧案卷表格：案卷号/题名/年度/保管期限/密级/状态（字典映射 + 状态标签）
- 保管期限、密级从字典接口拉取（retention_period / secret_level）
