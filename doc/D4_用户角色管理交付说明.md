## 二、接口说明

### 角色管理（`/api/system/role`）

| 接口 | 方法 | 路径 | 说明 |
|---|---|---|---|
| 分页查询 | GET | `/api/system/role/page` | 支持 roleName 模糊、status 筛选 |
| 全部启用角色 | GET | `/api/system/role/list` | 下拉框用 |
| 新增 | POST | `/api/system/role` | roleCode 唯一 |
| 编辑 | PUT | `/api/system/role` | roleCode 唯一（排除自身） |
| 删除 | DELETE | `/api/system/role/{id}` | 有用户引用时禁止删除 |

### 用户管理（`/api/system/user`）

| 接口 | 方法 | 路径 | 说明 |
|---|---|---|---|
| 分页查询 | GET | `/api/system/user/page` | 密码脱敏，支持多条件筛选 |
| 新增 | POST | `/api/system/user` | 密码必填 + 格式校验 |
| 编辑 | PUT | `/api/system/user` | password 为空不修改 |
| 删除 | DELETE | `/api/system/user/{id}` | 逻辑删除，admin/自己不可删 |
| 启用/禁用 | PUT | `/api/system/user/{id}/status/{status}` | admin/自己不可禁用 |
| 重置密码 | PUT | `/api/system/user/{id}/reset-password` | 重置为 admin123 |

> 所有 `/api/system/**` 接口需登录（Sa-Token 拦截，未登录返回 401）

## 三、安全与业务规则

| 规则 | 说明 |
|---|---|
| admin 账号保护 | id=1 超级管理员不允许删除/禁用 |
| 自我保护 | 不能删除/禁用当前登录账号 |
| 密码格式 | 复用 PasswordConstants 正则（8-16 位字母+数字） |
| 密码脱敏 | 分页查询返回的 password 恒为 null |
| 逻辑删除 | 删除用户走 del_flag，数据不物理清除 |
| 引用保护 | 角色下有用户时禁止删除角色 |
| 唯一性 | username、roleCode 全局唯一 |
| 操作留痕 | create_by/update_by 自动填充当前登录用户 |
