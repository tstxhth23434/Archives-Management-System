## 一、本次交付总览

D7 是前端的第一阶段，目标是把 D3-D6 的后端能力"可视化"：搭建 Vue3 前端工程，实现登录、动态菜单主布局、用户管理完整 CRUD，打通前后端。

| 模块 | 内容 |
|---|---|
| 前端工程 | Vue 3 + Vite 5 + Element Plus + Pinia + Vue Router + Axios + ECharts |
| 登录页 | 表单校验、调用登录接口、token 存 localStorage |
| 主布局 | 侧边栏动态菜单（后端菜单树驱动）+ 顶栏 + 内容区 |
| 用户管理 | 搜索/分页/新增/编辑/删除/重置密码，按钮级权限控制 |

## 三、核心设计（答辩可讲）

### 3.1 axios 拦截器（前后端契约）

后端统一返回 `Result { code, message, data }`，前端在**响应拦截器**里统一处理：

```
请求拦截器：自动给每个请求加 Authorization 头（token 来自 localStorage）
响应拦截器：
  code === 200  → 直接返回 data（业务代码拿到的就是数据本身）
  code === 401  → 清 token + 跳登录页（token 过期/未登录）
  其他 code     → ElMessage 弹错误提示
```

**价值**：业务代码不用在每个接口里判断成功/失败，一处处理，全局生效。

### 3.2 动态菜单（D5 后端的落地）

- 登录后调用 `GET /api/auth/menus`，拿到菜单树 + 权限码
- 菜单树存 Pinia，侧边栏根据菜单树**递归渲染**（目录=子菜单，菜单=菜单项，按钮不进侧边栏）
- 图标用后端存的 Element Plus 图标名动态渲染 `<component :is="menu.icon" />`

**价值**：菜单来自数据库，改角色权限 = 改数据库，前端零改动。

### 3.3 按钮级权限（D5 的 @SaCheckPermission 前端呼应）

前端 `userStore.hasPerm('system:user:delete')` 控制按钮显隐，后端 `@SaCheckPermission` 做最终校验——**前后端双重校验**，前端是体验优化，后端是安全底线。

### 3.4 路由守卫

```
未登录 → 强制跳 /login
已登录访问 /login → 跳首页
刷新页面（有 token 无用户信息）→ 自动拉取用户信息 + 菜单树
```

## 四、接口对接表

| 前端 api | 后端接口 | 说明 |
|---|---|---|
| login() | POST /api/auth/login | 返回 { token, userInfo } |
| getInfo() | GET /api/auth/info | 当前用户信息 |
| getMenus() | GET /api/auth/menus | 返回 { menus, perms } |
| logout() | POST /api/auth/logout | 登出 |
| pageUsers() | GET /api/system/user/page | 分页查询 |
| addUser() / updateUser() | POST/PUT /api/system/user | 新增/编辑 |
| deleteUser() | DELETE /api/system/user/{id} | 删除 |
| changeUserStatus() | PUT /api/system/user/{id}/status/{status} | 启停用 |
| resetPassword() | PUT /api/system/user/{id}/reset-password | 重置密码 |
| listRoles() | GET /api/system/role/list | 角色下拉 |

## 五、启动方式

```bash
# 1. 启动后端（8080）
java -jar target/Document-Management-System-0.0.1-SNAPSHOT.jar

# 2. 启动前端（5173）
cd dms-ui
npm install   # 首次
npm run dev

# 3. 访问 http://localhost:5173
```

## 六、关键约定（前后端对齐）

| 约定 | 值 |
|---|---|
| 成功 code | 200 |
| 未登录 code | 401 |
| 无权限 code | 403 |
| token 存储 | localStorage，key = dms_token |
| 请求头 | Authorization: <token> |
| 分页返回 | { records, total, current, size } |
| 密码规则 | 8-16 位字母+数字（前后端一致） |
